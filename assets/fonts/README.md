# Шрифты

В этой папке лежат локальные копии веб-шрифтов (woff2, подмножества Google Fonts),
чтобы сервис работал без интернета и без внешних CDN.

| Шрифт | Файлы | Лицензия |
| --- | --- | --- |
| **Roboto Condensed** (400–800) | `roboto-condensed-*.woff2` | Apache License 2.0 — см. `LICENSE-RobotoCondensed.txt` |
| **Inter** (400–700) | `inter-*.woff2` | SIL Open Font License 1.1 — см. `LICENSE-Inter.txt` |

Подключение описано в `../fonts.css`. Источник: Google Fonts (fonts.google.com).
